# SME_Academy

Reusable Git-backed SME training, wiki, library, simulation, and operational knowledge framework.

Reference implementation: `modules/empvpn`.

## v3.1 notes

- Library defaults to compact one-line rows.
- Details expand only when requested.
- Favorites, bookmarks, and notes are available in the Workspace tab.
- Sim choices auto-save locally and mark the repo as having unreplicated changes.
- Added `Changes_and_Recipes` area for normalized ServiceNow/change knowledge objects.
- Added `pending_contributions/` for future Curator-reviewed learner contributions.
- Planned encrypted user workspace files live under `users/<user_id>/`.

## Launch

Open `index.html` in a browser. Desktop Edge/Chrome is the target for future local repo write support via the File System Access API. Phones remain useful for view/test mode.
